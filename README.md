# Web3Whirl

Web3Whirl is a decentralized data management platform utilizing blockchain secure smart contract execution and distributed data storage capabilities.

With Web3Whirl, you get a lightweight tool that stays out of your way.

**What you get**

- Web3Whirl is a decentralized data
- management platform utilizing blockchain secure
- smart contract execution and distributed

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Whirl.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
